# Admin Panel upstream

`panel/` is [ClickHouse/librechat-admin-panel](https://github.com/ClickHouse/librechat-admin-panel) at commit
`fce9596f823e78f991c7ef60bb97d0ce15d72934` (tarball sha256 `88a58326cefe2a3875298fbfa0859d628de238d0f13cb5473bd6bf5beed4b59a`),
with K-AI changes edited directly in the source. License: AGPL-3.0 (`panel/LICENSE`); the modified source ships with the product.

K-AI changes (search for `kai` / Indonesian strings):
- Branding: logo/icon in `public/` and `src/assets/`, title, manifest, locales (LibreChat → K-AI platform), login view (`src/login-branding.css`).
- Users: account setup, ClickHouse access, agent access, readiness sections (`src/components/users/*Section.tsx`, `CreateUserDialog.tsx`, `AccountFields.tsx`); native user editing disabled (`canManage={false}`).
- Dashboard: "Perlu perhatian" panel (`ProblemsPanel.tsx`).
- Integrasi page (`src/routes/_app/integrations.tsx`, `IntegrationsPanel.tsx` with the database checklist, `SettingsSection.tsx` for batch model and limits, sidebar entry).
- Component tests for the Users sections: `../tests/UserDetails.test.tsx` (copy next to the components to run with vitest; kept out of the image build).
- Server functions for platform routes: `src/server/kaiAccounts.ts`, `src/server/kaiAgents.ts`.

Updating to a newer upstream commit: download its tarball, diff it against the commit above, and port the upstream
changes into `panel/` (not the other way round). `src/routeTree.gen.ts` is regenerated by the build; keep it in sync
when adding routes. Then build the image on the server (`make admin-up`), never on a laptop.
